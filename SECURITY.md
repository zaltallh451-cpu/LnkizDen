# Security

LnkizDen is unofficial PS5 homebrew. There is no warranty.

If LnkizDen crashes, hangs, or a setting is wrong, open a
[Bug report](https://github.com/aydencharles/onionHEN/issues/new?template=bug_report.yml).
Include firmware, version, how it was loaded, and logs from
`/data/LnkizDen/`.

To keep a report private, use this repository's Security tab.
